## Yapılan Düzenlemeler

### 1. Python 3.9 Uyumluluğu (`runner.py`)
`dict | None` ve `list | None` sözdizimi Python 3.10+ gerektiriyordu.  
`from typing import Optional` eklendi, tüm `X | None` kullanımları `Optional[X]` ile değiştirildi.

**Etkilenen satırlar:**
- `HarnessClient._get` — `params: dict | None` → `Optional[dict]`
- `_try_extract_embedded_json` dönüş tipi
- `evaluate_step` — `gt: dict | None`
- `run_test` — `conversation_id: str | None`
- `run_focus_group` ve `run_and_report` — `persona_ids: list | None`

---

### 2. Serverless Infra Timeout Fix (`runner.py`)
Harness API `timeoutMs=60000` ile çağrıldığında, sunucunun bekleme süresi serverless infra limitini (~30 sn) aşıyor ve HTTP 503 dönüyordu. `timeoutMs` 25 saniye ile kısıtlandı.

**Değişiklik:**
```python
# start_conversation ve send_message içinde:
timeout_ms = min(config.HARNESS_TIMEOUT_MS, 25_000)
```

---

### 3. Timeout → Gerçek Hata Yanıtı (`runner.py`)
`BOT_RESPONSE_TIMEOUT` durumunda sistem mock yanıta düşüyordu. Bu, bot hatasını test sonuçlarında gizliyordu. `_timeout_response()` fonksiyonu eklendi.

**Eski davranış:**
```python
bot_response = _mock_olly_response(step_num, max_steps)  # veri kirletiyor
```

**Yeni davranış:**
```python
def _timeout_response() -> dict:
    return {
        "response_action": "timeout",  # geçersiz → action_score 0
        "response_text":   "",         # boş → tone_score 2
        "manage_memories": None,
        "intent_state":    "none",
        "new_follow_up":   None,
        "_timeout":        True,
    }
```

Timeout olan adımlar artık raporda düşük skor ile açıkça görünür.

---

### 4. Webhook URL Whitespace Fix (`config.py`)
`.env` dosyasında `SLACK_WEBHOOK_URL` ve `WEBHOOK_URL` değerlerinin yanında boşluk ve inline yorum satırı vardı. `python-dotenv` inline yorumu tam temizlemediği için değer truthy geliyordu ve httpx geçersiz URL'e POST atıyordu.

**Eski:**
```python
SLACK_WEBHOOK_URL: str = os.getenv("SLACK_WEBHOOK_URL", "").strip()
```

**Yeni:**
```python
def _clean(val: str) -> str:
    return val.split("#")[0].strip()

SLACK_WEBHOOK_URL: str = _clean(os.getenv("SLACK_WEBHOOK_URL", ""))
WEBHOOK_URL:       str = _clean(os.getenv("WEBHOOK_URL",       ""))
```
